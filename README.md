# Лаборатория Жизни — HTML-страницы для QR-кодов

Полный комплект мобильных страниц для информационных стендов экспозиции **«Лаборатория Жизни»** Музея Мирового океана.

## Стиль
- Цветовая палитра: глубокий океанский синий + акцентный cyan
- Чистая типографика, удобно читается на телефоне
- Переключатель языков: **RU / EN / 中文** на каждой странице
- Адаптив под мобильные устройства (QR-сканирование)

## Как использовать
1. Разместите папку `lab-life-qr` на хостинге музея.
2. Для каждого стенда создайте QR-код, ведущий на соответствующий HTML-файл.
3. Все страницы самодостаточны (стили и скрипт внутри / рядом).
